# Always-Open Assistant Service Page

This is Michael's first live asset for the AI Virtual Receptionist + Admin Follow-Up consulting offer, focused on home service businesses.

## What It Does

The page explains a practical service:

> Help home service businesses stop missing calls, capture job details, and turn conversations into clear staff follow-up actions.

## Local Preview

Open `index.html` in a browser.

## Deployment Direction

This can be deployed as a static site on Vercel.

Recommended first deployment path:

1. Put this folder in a GitHub repository.
2. Import the repository into Vercel.
3. Deploy as a static site.
4. Use deployment screenshots/errors as learning material for the LLM wiki.
